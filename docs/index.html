Cómo se usa

How to use it

PC gamer

Host PC

  1. Abre Lumen.exe (o Setup la primera vez).
  2. Open Lumen.exe (or Setup the first time).
  3. Entra con un usuario.
  4. Sign in with a username.
  5. Pulsa Compartir este PC.
  6. Click Share this PC.

El otro PC

The other PC

  1. Misma wifi: pulsa Conectar.
  2. Same wifi: click Connect.
  3. Otra casa: pega el código (IP) y Añadir.
  4. Elsewhere: paste the code (IP) and Add.
  5. Si sale un PIN, lo escribes en el host.
  6. If a PIN appears, type it on the host.

Qué hace y qué no

What it does and what it doesn’t

Va

Works

  • Misma red, con un clic.
  • Same LAN, one click.
  • Monitor virtual, 4:4:4 en LAN, lápiz.
  • Virtual display, 4:4:4 on LAN, pen.
  • Otra red si el router abre puertos (UPnP) o si las dos tienen Tailscale.
  • Remote if UPnP opens ports, or both PCs run Tailscale.

No va (aún / nunca así)

Doesn’t (yet / by design)

  • No hay relay mundial de pago tipo Parsec. Si tu ISP es CGNAT, la IP pública no basta.
  • No paid global relay like Parsec. CGNAT ISPs won’t expose you with just a public IP.
  • No es el protocolo de Parsec. Es GameStream.
  • Not Parsec’s protocol. It’s GameStream.
  • Linux/macOS cliente: usa Moonlight; este launcher es Windows.
  • Linux/macOS clients: use Moonlight; this launcher is Windows.
